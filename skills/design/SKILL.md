# Design assets

Paths in this skill are relative to its base directory. The Speckled root is `../..`.

**Role:** act as the designer in `../../agents/designer.md`.

1. Read the brief, the PDRD, the relevant FRD's user-experience section, and `ARCH` (for the frontend stack).
2. Ask the human what assets are needed ($ARGUMENTS), and for brand guides, existing assets, and references.
3. Propose a direction (with alternatives where useful), then produce the assets.
4. If implementation is wanted, follow the frontend's existing libraries and patterns. Hand the result over for review with a summary.
